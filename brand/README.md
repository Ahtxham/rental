# Musafir, printed

Artwork for the cars and for the hand-outs. Everything here is generated by the
scripts in `src/`, so a change goes in one place and every piece picks it up.

```bash
# Regenerate everything after an edit
python src/marks.py && python src/codes.py && python src/pieces.py && python src/assets.py
```

## Before anything is printed

`src/pieces.py` has `PHONE = "03XX XXXXXXX"`. That is a deliberate placeholder.
Put the real number in, regenerate, and check the proof. An X on a proof is a
question somebody asks; a plausible wrong number is a box of paper in the bin.

The same number should go into `NEXT_PUBLIC_CONTACT_PHONE` and
`NEXT_PUBLIC_CONTACT_WHATSAPP` on the server, so the printed card and the
website agree.

## What each file is

| File | Size | Where it goes |
| --- | --- | --- |
| `pdf/decal-600x170-cut.pdf` | 600 × 170 mm | Rear windscreen. Cut vinyl. |
| `pdf/decal-600x170-proof.pdf` | 600 × 170 mm | The same thing on glass, to look at. Not for cutting. |
| `pdf/decal-qr-patch-70x70.pdf` | 70 × 70 mm | Printed white sticker, applied beside the band. |
| `pdf/seatback-a5.pdf` | A5 + 3 mm bleed | Headrest pocket, handed to passengers. |
| `pdf/lender-a5.pdf` | A5 + 3 mm bleed | Car owners. Workshops, car washes, tyre shops. |
| `pdf/card-a6-front.pdf` / `-back.pdf` | A6 + 3 mm bleed | Two-sided hand-out. Front rents, back recruits. |

`print/*.svg` are the same pieces as vector, for a shop that would rather have
SVG than PDF. `logo/` holds the mark on its own, the lockup, and the app icons.
`logo/concepts/` is what was tried and not used.

## For the vinyl shop

**Two colours: white and amber.** White for the wordmark, the address and the
uprights of the M. Amber for the rule, the phone number and the V inside the M.

Near-black is not an option on the rear glass. Most rear windows in Lahore are
tinted, and dark vinyl on dark glass is a sticker nobody sees.

**Amber is `#FFB020`.** Cut vinyl only comes in the colours it comes in, so ask
for the nearest golden amber in whatever cast vinyl they stock and hold the
sample against the printed proof in daylight before they cut twelve of them.
Cast vinyl, not calendered, if the price difference is tolerable: calendered
film shrinks and lifts at the edges after a Lahore summer.

**The amber V overlaps the white uprights in the file.** Either apply white
first and amber on top, or run Trim in Corel so the two colours butt instead of
stacking. Their call, but they should decide before cutting rather than during
weeding.

**Type is already outlined.** There is no font to install and nothing will
substitute. If they ask for outlines, the answer is that it is already done.

**The QR is a separate printed patch, not cut vinyl.** A 41-module code is
roughly eight hundred individual squares to weed off the backing by hand. No
shop will do that well and none will do it twice. Print it on white vinyl,
apply it beside the band.

## For the paper shop

3 mm bleed and crop marks are in the files. 300 gsm for the A6 cards, matt
laminate if the seat-back card is going to live in a car, because a gloss card
in a footwell picks up every fingerprint in the city.

The seat-back card is nearly solid black. Ask for it on a digital press rather
than the cheapest offset run available, or the large dark area will band.

## The QR codes

Each piece carries its own, and each one has a different `?s=` tag:

| Tag | Piece | Lands on |
| --- | --- | --- |
| `s=glass` | Car sticker | Home |
| `s=seat` | Seat-back card | The cars |
| `s=flyer` | Lender flyer, A6 back | Rent your car |
| `s=card` | A6 front | Home |

Nothing reads that parameter, which is the point: it sits in the nginx access
log, so counting scans per piece is `grep 's=seat' access.log | wc -l`. When the
sticker tag climbs and the flyer tag does not, that is the answer about where to
spend the next afternoon.

Every code was decoded back with OpenCV, a different implementation from the one
that drew them, at the size it prints at. The smallest module on any piece is
0.68 mm, comfortably above the 0.5 mm where phone cameras start to struggle.

## The rear glass, honestly

A QR wants roughly ten times its own width in scanning distance, so the 46 mm
patch reads from about half a metre. That is the car behind you at a red light
and nothing else.

The thing that actually works at three car lengths is `musafircars.com` set at
40 mm of cap height, which is why it is the biggest thing on the band and why
the company name is smaller than the address. Nobody types a name into a
browser.
